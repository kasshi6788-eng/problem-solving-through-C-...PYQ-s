Write a program to enter student details including Roll Number, Name, Fee, and Date of Birth (nested structure), and display all details sorted in ascending order of their Roll Numbers.

Answer: This solution applies a nested structure configuration to hold date elements, executing a record-level structure swap sort whenever roll number indices cross relational validation checks.

#include <conio.h>
struct Date {
int day;
int month;
int year;
};
struct Student {
int rollNo;
char name[30];

struct Date dob;
};

{
struct Student s[5], temp;
int i, j, n = 5;
